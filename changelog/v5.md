# **Changelog - v5**

## [5.0.0](https://github.com/nishkohli96/eslint-config/tree/v5.0.0)

**Released - 1 November, 2026**

### ✨ Enhancements

- Migrate package manager from `yarn` to `pnpm`; examples now consume local packages via `workspace:*`
- Add **dependabot.yml** and update `checkout` and `setup-node` actions to `v6`
- Support **ESLint 10**: peer deps `eslint` and `@eslint/js` are `>=10`; `eslint-plugin-react` is wrapped with `fixupPluginRules` from `@eslint/compat` and the React version is resolved by the package, since the plugin's `detect` setting and rules use context APIs removed in ESLint 10
- Pin `typescript` to `~6.0.3` in the v10 examples (`typescript-eslint` does not support TS 7)
- Update **Docusaurus** from `3.9.2` to `3.10.2`.
- Remove `examples/eslint-v9`; `eslint-flat-config` now supports ESLint 10 only (ESLint 9 users stay on v4.x)
- Update supported node versions
  ```
  "engines": {
    "node": "^20.19.0 || ^22.13.0 || >=24"
  }
  ```

### 🔧 Fixes

- Organize changelog files by version
- Update logo url for `README.md` for both packages and repo root.
- Set `no-useless-assignment` rule to `warn`
